# Actuarial Reserving Model

## Project Overview

This project demonstrates fundamental actuarial loss reserving techniques using Python and Excel.

The model analyzes claim development over time, calculates loss development factors (LDFs), estimates ultimate losses, and determines required claim reserves. These concepts are commonly used by actuaries to estimate future claim obligations and assess insurance company liabilities.

## Tools Used

* Python
* Pandas
* Microsoft Excel
* PivotTables
* PivotCharts

## Key Metrics Calculated

* Development Factor 12→24: 1.30
* Development Factor 24→36: 1.08
* Combined Development Factor: 1.404
* Ultimate Loss Estimate: $196,560
* Current Paid Loss: $140,000
* Required Reserve: $56,560

## Analysis Performed

* Generated insurance loss development data using Python.
* Created a reserving dataset for multiple accident years.
* Calculated loss development factors (LDFs).
* Estimated ultimate losses using development factors.
* Calculated outstanding claim reserves.
* Analyzed loss development by accident year.
* Built PivotTables and PivotCharts to visualize claim development trends.

## Business Insight

Based on the loss development analysis, the estimated ultimate loss for Accident Year 2023 is $196,560. Since only $140,000 has been paid to date, the insurer should maintain an estimated reserve of $56,560 to cover future claim payments.

This project demonstrates how actuaries use historical claim development patterns to estimate future liabilities and support insurance company financial planning.
